Zemineirinho — versão com login

Arquivos: index.html, manifest.webmanifest, sw.js e ícones.

IMPORTANTE: esta versão exige usuários no Supabase Auth e perfis em public.profiles.

Usuários: crie os usuários no Supabase Dashboard > Authentication > Users. Depois associe os perfis conforme as instruções fornecidas no chat.

Garçons: Lima, Carla e Garçom Extra.
Administrador: usuário com role admin.

O aplicativo usa o mesmo banco Supabase e exige HTTPS para instalação PWA.
